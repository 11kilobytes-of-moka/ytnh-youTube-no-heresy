YouTube No Heresy is a small project made by @11kilobytes-of-moka to bring back the original like icon instead of YouTube's new heart icon. It works by injecting its file, `index.js`, to make it work. I made it out of despair because I HATED that heart icon, and I saw many people who also don't like it.

So I decided to fix it myself. Because begging Google won't help.

This took me time because I had studies and exams, and I also had to reverse-engineer YouTube so I could know what to do and how to code.

So, heresy generally refers to a belief or opinion that contradicts established religious doctrine or, in broader non-religious usage, accepted beliefs. It can also have a religious meaning, but this project itself is NOT for any religious purposes.

For more explanation, visit the Wikipedia page for *Heresy*: [Heresy, Wikipedia Page in English](https://en.wikipedia.org/wiki/Heresy) and look for the "Non-religious usage" section on the Wikipedia page to get the meaning I'm using.

## Installation

Installation is pretty simple, so follow these steps for either Chromium (S) or Firefox.

### Chrome

1. Download the source code from GitHub.
2. Go to `build/`.
3. Go to `0.1.0/` (this current version).
4. Go to `chromium/`.
5. Enter Chrome → Manage Extensions → Enable Developer Mode → Load Unpacked → Select the chromium folder.

### Firefox

1. Download the source code from GitHub.
2. Go to `build/`.
3. Go to `0.1.0/` (this current version).
4. Go to `firefox/`.
5. Inside, you will find a ZIP file containing the extension. Copy it wherever you want or just leave it there.
6. Open Firefox, paste this into the URL: `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → Select where the ZIP file is located. (NOTE: If you are in Firefox, you will need to do this every single time the browser reboots.)

And that's it for now!
